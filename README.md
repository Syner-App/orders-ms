<h1 align="center">orders-ms</h1>

<p align="center">Microservicio de ordenes del proyecto <strong>Syner</strong>, construido con NestJS y gRPC.</p>

## Descripción

`orders-ms` es el microservicio encargado de la gestión del catálogo de productos dentro de la arquitectura de microservicios de Syner. Expone su API exclusivamente mediante **gRPC** (sin servidor HTTP) y persiste los datos con **Prisma** sobre **Postgresql**.
